# 使用说明

本 skill 根据用户提供的流程截图及《B端营销术语解释与商家版转述合并版》制作。流程为：通读输入 → 逐句扫描 → 等价通俗替换 → 按固定四项输出 → 附加可选建议。

输出固定为【原文】【改写后商家版】【识别到术语】【改动说明】；整段页面按段落或组件分条。已经易懂的文案标记【无需修改】；风险和限制不得弱化，不评审业务逻辑，不新增业务规则。

将 merchant-marketing-rewrite 整个目录作为 skill 包使用，保留 SKILL.md 与 references/marketing-terms.md 的相对位置。单独使用 SKILL.md 时，应同时提供参考表。
