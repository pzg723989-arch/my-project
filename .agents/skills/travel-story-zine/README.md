# travel-story-zine / 旅日小志

将整个目录作为 Skill 包使用，保留 references 相对路径。它定义编辑流程和小程序数据接口，不包含小程序源码、模型服务或 PDF 渲染器。

示例请求：

> 使用 travel-story-zine 记录 2026 年 10 月 3 日。地点：伊宁—赛里木湖—果子沟。上午出发，中午到湖边，傍晚经过果子沟。风大，我们在车里吃午饭。照片见附件；第 3 张一定保留。先生成草稿，使用轻叙事型。

> 把 Day 03 的主图换成 photo-07，只重新排这一个跨页，保留手改文案和其他日期。

> 我确认这一天的内容，请加入整本；导出前检查必留照片、裁切与正文密度。

每日 JSON 示例刻意不含照片，因此不是完成选片的示例；展示在缺少素材时如何保持草稿、说明未检查项目，不用假图填充。接入应用时由应用提供真实照片资产、持久化、版本校验、预览与 PDF 渲染能力。
