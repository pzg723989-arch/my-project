# 排版与验收

## 六个模板

| template | 用途与布局 |
| --- | --- |
| full_bleed_opening | 环境主图开篇；只有主体安全及分辨率允许时满版，否则保留边框；不强制横跨中缝 |
| paired_whitespace | 两张有关联的竖图或同场景；每页一图，较大留白 |
| large_small_echo | 环境大图与生活细节小图；通过尺寸差产生节奏 |
| human_sequence | 2—4 张人物、食物、街巷或途中照片；同一叙事组而非随意拼图 |
| photo_story | 1—2 张照片与一段记忆；文字置于独立空白区域 |
| dark_transition | 暗调、夜景或章节收尾；近黑底，正文与背景对比清晰 |

竖版单页、左右两页组成一个跨页。默认参考画布为数字预览 3:4 单页比例，此比例不是印刷规格。暖白和近黑按照片色调与章节节奏交替，不要求每页轮换。正文优先清晰可读字体；手写字体仅少量用于标题，缺字体时用可用字体替代并说明，不私自下载授权不明字体。无需重调原片色彩或添加滤镜。

有文字的页面保留实际文字区域，按渲染字体与字号测量；不能仅靠 JSON 判断文字适配成功。未渲染时文字溢出检查为 not_run。

## 篇幅

| 入选照片数 | 建议跨页数 |
| --- | --- |
| 0 | 不生成照片排版，保留资料草稿 |
| 1—3 | 1—2；允许更多留白，注明素材偏少 |
| 4—8 | 2—3 |
| 9—15 | 4—5 |
| 16—25 | 5—7 |
| 26 及以上 | 建议精选到 25 以内；必留超过上限时说明冲突并让用户选择扩页或缩选，不静默丢弃 |

每个跨页是 2 个页面，页数须明确单位。封面、封底和目录单独计数，不伪装成每日跨页。纯照片或仅地点标签跨页目标约占一半；不为了比例删除必要信息。照片不能仅为填满模板而重复使用，重复展示须有用户许可或明确设计理由。

## 裁切和输出

先检查图片横竖比、主体和人脸、清晰度，再选择模板。禁止把人脸或重点景物放在装订中缝；中缝安全距离按印厂参数检查，未知时不跨缝放置关键主体。无主体位置分析时使用 contain，不凭空填写人脸框。

印刷有效 DPI = 裁切后沿对应方向的像素数 ÷ (放置尺寸毫米 / 25.4)，两个方向分别检查。像素或尺寸未知则结果为未检查。目标 DPI 和最低可接受值按输出规格确定，不把固定 300 DPI 当作所有用途的通过标准。检查出血、内边距及装订损耗；规格未知不得声称印刷就绪。

## 必做验收

1. 事实：每句叙事有来源；没有虚构情绪、关系、对话、具体地名或事件；日期与时区冲突已处理。
2. 选片：照片引用存在；原图保留；无 hidden 照片入选；must_keep 全部入选且至少出现一次；主图来自入选集。
3. 布局：选中照片均有位置，无未授权重复；模板有效；box/crop 不越界；所有文字块引用有效且正文文字被编排。
4. 视觉：实际检查主体、人脸、中缝、文字溢出、色彩关系与清晰度；没检查的项目明确 not_run。
5. 密度：默认 2—4 处正文、标题长度与段落长度合理，约半数跨页无正文；信息不足和极简档允许少于默认。
6. 状态：只有用户明确确认才 confirmed；不改变其他已确认日期；版本冲突无覆盖；未落盘不得报告 saved。
7. 合册：日期目录及跨页顺序可追溯，页数按真实输出计算；空日期只提醒；草稿导出范围明确。
8. PDF：只有工具实际输出且文件可读才给下载路径；检查实际页数、字体、漏图、裁切和文字。印刷检查单独报告，不能用普通 PDF 成功替代。

验收失败时修复能修复的编辑问题；依赖未提供素材、渲染能力或用户事实确认时，继续完成其他项目并清楚列出阻碍。不能把结构校验通过等同于审美、事实或印刷全部验证通过。
